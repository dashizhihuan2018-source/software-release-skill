# 软件公开发布 · software-release

一个中文 Codex 技能，用来实际完成软件公开分发，而不止输出调研建议。覆盖可携带构建、免费官网、境外托管与 VPS 申请、域名/DNS/HTTPS、公开 Git 与 Release、版权审查、海报/宣传视频、功能教程以及公开回读验收。

## 它解决什么

- 把构建、对应源码、下载资产、站点部署和用户接受分开记录，避免“push 成功 = 全部交付”。
- 区分静态托管与 VPS、平台子域名与独立域名、免费试用与长期免费，不承诺申请必过或永不收费。
- 从真实菜单与运行结果写功能介绍和教程，不把禁用项、演示素材或有限兼容写成完整功能。
- 审查软件组件、字体、图片、音乐和视频来源；不能用“独立重写”“软件免费”代替权利判断。
- 保留敏感数据和用户原件，只公开获准范围；Key、私人路径、真实客户文档不进入发布包和仓库。
- 实施发布后，从公开 URL 下载并核对最终 SHA-256，再检查源码提交、网站和桌面/移动浏览器。
- 为 macOS 零预算直装说明单应用首次信任，并用干净环境原包启动 smoke 排查开发机依赖；不混淆公证、首次弹窗和 GUI 验收。
- 按约定目标及时收尾，保留独立限制；不因额外域名审核或新迁移候选出现就无限延长已完成的发布。

## 安装与使用

将本仓库中的 `software-release` 文件夹复制到你的 Codex 技能目录（通常为 `~/.codex/skills/`，以你的环境配置为准）。该目录应直接包含 `SKILL.md`、`agents` 和 `references`；不要把整个项目工作区复制进去。刷新技能列表或重开会话后使用：

```text
请使用 $software-release，实际把我的软件发布为免费官网与公开下载。
先核对要公开的范围、目标平台和费用，再制作并验证发布包、网站、教程与宣传素材。
```

也可只执行具体阶段，例如更新已授权站点、检查某次 Release，或为已有应用补齐真实功能教程。技能默认可自动发现，但不会因被选中而获得额外的付费、账户、上传、许可或生产变更权限。

## 文件结构

```text
software-release/
  SKILL.md
  LICENSE
  agents/openai.yaml
  references/free-hosting-domain.md
  references/site-media-qa.md
  references/macos-free-distribution.md
```

主文件保留共享流程与验收门；三份参考按需加载。没有未运行的部署脚本、演示账户、默认凭证或预设私人服务器地址。具体工具依当前 Codex 环境提供的构建、Git、浏览器、设计和托管能力选择；缺能力时如实报告，不能编造成功。

## 验证与维护

可使用本机 `skill-creator` 附带的 `scripts/quick_validate.py` 检查技能结构。结构校验不证明外部服务已经开通，也不代替真实发布验收。服务条款与免费额度会变，执行当天需核查参考中的官方资料。

建议用自建无隐私样本演练：零预算、无开发者会员、只需静态官网、已有私有代码且不愿开源、域名审核未过、上传写操作超时、官网仍指向旧包等情况。测试外部写入前取得对应授权。
