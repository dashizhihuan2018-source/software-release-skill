# 软件官网：产品叙事、真实界面与标题字体

本模块是软件发布流程中的官网能力，不是另一个软件重写目标。适用于创建或调整发布网站；不因选中本技能而重做无关站点。

## 先讲完整产品，再展开特色

主标题与信息顺序依据用户认可的海报、视频及真实产品定位。先表达完整产品的使用链路，再将某个亮点放入所属功能，不因用户举了GIF、OCR等例子就把整站变成该单项工具网站。宣传语不能扩张为片库、性能、授权或“全网唯一”的无证承诺。

用户要求参考已有网站时，先检查该网站实际UI，提取色彩、字体、留白、层级及产品舞台，独立实现目标软件内容。PDF Master的暖纸、深蓝产品舞台和朱红强调可作为经用户选择的参考，不是所有软件必须共用的外观。

## 标题默认规范

- 新建软件发布网站，且未指定其他品牌规范时，中文主标题、章节标题及功能标题使用**思源宋体粗体（Source Han Serif CN Bold），font-weight:700**；正文保留易读无衬线字体。用户本次字体选择与既有品牌要求优先，不自动覆盖所有旧站。
- 提供真实可再分发的字体资源，优先本地WOFF2；只写font-family、依赖开发者电脑安装或给Regular加粗，不算交付了思源宋体Bold。核对字体内部家族、真实字重与中文覆盖。
- 字体放在网站独立fonts目录，以相对URL引用，随站保留完整OFL及版权。字体许可独立于网站/软件许可；不能将OFL字体改称MIT、自有字体或“无版权”。
- 子集化或格式转换前检查上游许可与保留字体名要求；保留源和转换范围。缺字、回退、网络失败不能以“看起来像宋体”替代核验。用户未授权时不安装系统字体、修改系统字体或依赖外部字体CDN。

示例（文件名及路径应对应实际资源）：

```css
@font-face {
  font-family: "ReleaseTitleSerif";
  src: url("fonts/SourceHanSerifCN-Bold.woff2") format("woff2");
  font-style: normal;
  font-weight: 700;
  font-display: swap;
}
h1, h2, h3 {
  font-family: "ReleaseTitleSerif", "Songti SC", serif;
  font-weight: 700;
}
```

CSS别名不是修改字体内部名称的许可。引用路径应与页面/样式表所在目录及托管子路径一致。

## 最新版实拍门

用户要求最新版真实截图时，先核对正式App路径、运行进程、版本/build、主程序摘要与当前发布记录，再在该App打开自建或许可清楚的演示素材。不能把旧版截图/录屏加“最新版”标签，或只替换封面却继续加载旧版视频。旧资料可保留为非公开工作证据；用户不允许旧版时从当前展示与部署白名单移除。

保存原始截图及捕获身份，不重绘或生成控件来冒充真实界面。当前媒体/列表含私人内容时改用可公开样本，并保护用户未保存工作；不要上传尚未审查的原图。截图、真实导出、操作录屏和宣传合成分别标识，不用导出文件证明UI点击完整验收。

## 验收与同步

1. 检查所有目标标题的计算字体/700字重、字体请求状态及FontFace加载状态；再看实际中文像素，避免静默fallback。检查桌面和明确尺寸手机的换行、缺字及溢出。
2. 发布前按允许清单打包HTML/CSS、字体、许可和最新素材，记录摘要。只提交网站/技能必要文件，不上传记忆、凭据、用户媒体或整个脏工作区。
3. 用户要求同时同步Git与腾讯云时，两个目标分别回读提交/部署与实际资源摘要；Git push不等于腾讯部署。沿用已授权服务器，隔离目标路径并保留可恢复前像，不能借同步改DNS、安全策略、内核、其他业务或购买资源。
4. 字体、公网内容、浏览器视觉、软件操作与人类接受分开报告。未获得线上像素时明确标注，不拿本地截图冒充公网验收。
