# 免费托管、境外服务器与域名

编写时核对日期：2026-10-26。服务范围、额度、条款和地区资格会变；执行当日重新打开对应官方页面，使用账户实际控制台与账单结果，不把本文的候选当成已获资源。

## 先区分四件事

| 需求 | 合适的第一路径 | 不代表什么 |
| --- | --- | --- |
| 静态官网、教程、下载链接 | 免费静态托管，下载大包用 Release 资产 | 不是独立 VPS、不能随意运行长期后端 |
| 零费用公开地址 | 平台分配的子域名 | 不是拥有一个独立注册域名 |
| 自定义域名 | 已有域名，或用户选择并批准注册费用 | DNS 托管免费不代表域名注册/续费免费 |
| 长期服务进程、数据库、特定地区实例 | VPS / 云实例或明确匹配的后端平台 | “免费试用”不等于永久零费用或有现货 |

“国外/境外”需确认用户要的是特定区域的计算实例、无大陆节点部署，还是公开可访问地址。CDN 是全球边缘分发，平台公司所在地或 DNS 查询结果不能证明全部数据驻留地区；有区域/合规要求时查看服务协议和实际资源区。

## 路径 A：静态官网 + 公开 Git + Release

### GitHub Pages

适合已经授权公开代码/网站、希望仓库与官网一起维护的项目。GitHub Free 可从公开仓库使用 Pages；适用范围和配额以[官方限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)为准。Pages 不适用于所有商业交易或 SaaS 场景，不能因项目“软件免费”就忽略平台条款。

1. 确认仓库所有者和公开范围；先审查允许目录及历史，再创建/推送。安装器、大视频不要默认放 Git 历史。
2. 按实际项目选择分支目录（例如 docs）或现有 Actions 部署流程。不要替换项目已经使用的部署方式而不说明。
3. 在仓库 Pages 设置确认发布来源，等到具体部署显示成功并回读 URL。默认域名形式可为账户站点或带仓库路径的项目站点，实际 URL 以控制台为准。
4. 从带项目路径的线上 URL 检查 CSS、字体、图片、跨页导航和下载；以 `/` 开头的资源引用可能跳到域名根目录。
5. 用 GitHub Release 等适合的渠道分发安装包，官网链接到相应版本，而非开发临时 URL。回读最终资产哈希与源码标签。

自定义域名按[GitHub 官方说明](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/about-custom-domains-and-github-pages)操作；绑定和验证归属是不同步骤。不要让未绑定的 DNS 悬空造成接管风险。

### Cloudflare Pages

可作为静态托管的另一选择。官方支持把预构建资产[Direct Upload 到 Pages](https://developers.cloudflare.com/pages/get-started/direct-upload/)，并给项目分配 pages.dev 地址；实际项目名可能因占用而变化。Git 集成和直接上传的工作方式不同，先选适合后续维护的一种，不假定能无缝互换。

1. 使用用户已有账户或让用户完成所需注册/登录。核查当前套餐、文件/构建限制与项目权限。
2. 只部署审查后的网站目录；不要将工作区、备份、密钥或软件测试数据一起上传。
3. 回读部署 ID、production/preview 属性、实际 pages.dev URL；预览地址不自动代表正式站点。
4. 自定义域名按[官方绑定说明](https://developers.cloudflare.com/pages/configuration/custom-domains/)先关联项目，再按域名类型配置 DNS。不要只写一条 CNAME 就宣称已接入。
5. TLS、主域重定向、静态资源和发布内容都通过后，才更新对外宣传入口。

静态托管可能不满足所有后端、地区或经营用途；需要这些能力时单独评估，不在“免费官网”步骤中偷偷新增付费服务。

## 路径 B：境外 VPS 的申请和安全上线

仅在用户确实需要实例时进行。候选例为 OCI Always Free：官方区分[限时 Free Trial 与 Always Free](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier.htm)，而[账户 FAQ](https://www.oracle.com/cloud/free/faq/)说明身份/卡验证、区域容量不足等条件；[资源规则](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm)也需现场核对。不把旧的 CPU/内存配额写死，不承诺申请成功或资源永不回收。

### 申请前的决策

- 确认区域、CPU 架构、内存、磁盘、流量、公开 IP、备份、长期费用上限及是否接受卡验证。免费计算不代表所有磁盘/IP/流量都免费。
- 用户拒绝绑卡或任何可能扣费时，不代填卡、不升级账户、不买实例；可先完成静态官网并列出 VPS 的具体未完成条件。
- 注册、身份和支付验证由用户按真实信息完成。不得为额度反复注册或制造假账户。
- 保存公开的资源类型、区域、费用预览和状态即可，不记录身份证、卡号、验证码或联系信息到公开证据。

### 有授权与资源后才创建

1. 在控制台确认资源明确处于允许的免费/预算范围；试用赠金会到期的实例不能标为 Always Free。
2. 创建最小所需实例与磁盘。SSH 使用用户批准的公钥；私钥留在安全本机位置，不上传 Git、不回显。
3. 按服务需要开放端口；管理端口限制来源，避免无关数据库或管理界面对公网开放。不要把防火墙“全开”当作连通性修复。
4. 部署已测试的网站/服务，配置系统服务、日志轮转、备份与必要更新；不安装与发布无关的软件。
5. 独立验证 SSH 身份、公网地址、服务健康、重启恢复、HTTPS 和实际费用状态；预算告警并不等于强制费用上限，明确平台是否真能硬限制。
6. 记录恢复和退休路径；停机、销毁实例、删除磁盘或迁移 DNS 需要对应授权，不为省费擅自删用户资源。

容量或审核受阻时，报告控制台的实际错误与当前阶段。有限重试后停止，不能把“已填申请”写成“已开服务器”，也不要通过付费升级绕过用户零预算要求。

## 路径 C：地址、域名与 HTTPS

### 零费用先拿可用子域名

静态官网优先使用平台给出的 github.io / pages.dev 地址，不需要先注册独立域名。已经有服务器且需要动态 IP 解析时，可评估 [DuckDNS](https://www.duckdns.org/about.jsp)：它提供 duckdns.org 下的免费子域名指向指定 IP，不是独立顶级域名所有权，也不提供 VPS。解析记录类型和使用条件必须与实际部署方式匹配。

不要把网上所谓“免费域名申请”当成一定获批、稳定可续期或可转移；涉及人工审核的服务，只有回读真实分配和可管理的域名后才报告已取得。

### 独立域名注册

1. 确认名称及商标冲突风险、注册商、首年和续费价格、附加项目、转移/赎回规则、隐私选项。查到“可注册”不是已购买或已获批。
2. 涉及费用或合同最终提交前，向用户说明确切方案并取得对应授权；注册资料、验证码和支付步骤由用户安全完成。
3. 域名取得后核对注册商控制台状态和 DNS 管理权限，再绑定托管平台。不要变更同域已有邮件、验证 TXT、子域服务或 NS 而不评估影响。
4. 按主域/子域选择 A、AAAA、CNAME 或平台要求的记录；先记录旧值与可恢复方案。遵守平台验证方式，不凭记忆填写 IP。
5. 权威 DNS 与公共解析结果均正确、证书签发完成、HTTPS 页面可用、重定向正常后再宣称上线。DNS 缓存和证书等待不靠关闭浏览器安全警告解决。

## 状态回执

为每条资源单独记录阶段与只读证据：

`已选择方案 → 用户身份操作待完成 / 已提交 → 审核中 → 已分配 → DNS 验证 → TLS 可用 → 网站/服务验收通过`

静态站部署可以完成而 VPS/独立域名未申请；这应诚实交付为部分完成，附真正可用的平台 URL。不要借“用户要走通”跨越收费、身份、许可或安全边界。
