用于零预算、自包含桌面 App 的直接下载路线；不替代 App Store 审核。执行时重新核对 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 和 [GitHub 运行器文档](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)，服务条件、系统提示和可用标签可能变化。

## 不混淆四种结论

| 结论 | 证据及边界 |
| --- | --- |
| 无需开发环境 | 最终包依赖闭包、系统 PATH 下辅助工具、自建输入实际运行；不表示所有功能离线或第三方 AI 免费 |
| 签名完整 | strict/deep 校验与签名身份；ad-hoc 不是 Developer ID，也不是恶意软件安全认证 |
| 首次信任 | 浏览器下载后的实际隔离属性、系统提示及用户操作；curl 或 CI 启动不能替代 |
| 功能可用 | 实际桌面关键操作、保存重开与原件完整；进程存活不能替代文档显示或编辑验收 |

检查本机既有 Gatekeeper 状态。若全局评估已关闭，记录其局限，不把本机能启动写成默认安全 Mac 首次体验通过，不擅自改变全局设置。

## 首次安装教程与用户决定

提供可信下载来源、版本/架构/最低系统、完整包哈希、拖入应用程序的操作与未公证风险。按 Apple 当日说明，仅当用户确信来源可信且未被篡改时，说明尝试打开后可在“系统设置 → 隐私与安全性”选择“仍要打开”并再次确认的单应用例外；受管理设备可能不可用。不承诺任何 Mac 都出现同一按钮。

恶意软件、损坏/篡改警告、无例外入口或组织策略阻止时停止，检查原包/联系开发者或管理员；不把它们一律当普通身份未验证。不提供关闭全局保护、批量清隔离属性、伪造证书或替用户同意信任的流程。

免费非商用不是组织免年费资格。无合法身份和签名材料时不购买会员、不冒充机构、不宣称已公证。用户接受单应用首次确认后，不把“所有系统首次无提示”强加为目标；仍如实保留浏览器首次实测状态。

## 低成本独立启动 smoke

已有授权的公开仓库可考虑当前免费标准 GitHub-hosted 运行器；先核对账户、仓库可见性、架构与标签。不要为免费测试擅自公开私有源码，或选择付费 large/xlarge；不要把历史系统补丁号/标签永久写成模板。

建议将 smoke 与构建分开：

1. 用只读权限和有界超时，从官方公开 URL 下载**已发布的原包**，对照受信任清单核对大小/哈希、镜像完整性、版本、架构与签名；不重建、重签或改变安全设置后再冒称原包通过。
2. 只在一次性运行器临时目录展开副本，不替换用户正式安装。以系统级最小 PATH 测辅助工具，避免开发机缓存或包管理器掩盖缺依赖。
3. 现场创建无隐私样本，检查能回读；通过系统正常启动途径向 App 请求打开，核对真实 bundle/进程路径，观察有界存活，再请求正常退出并验证退出。不强杀，不自动丢弃文档。
4. 等待实际 job 终态并读取关键日志；记录运行 URL、实际 OS/架构、安全评估状态、下载哈希及检查范围。失败需说明哪一层，不能只看 workflow 总标题。

这证明测试环境中的原包启动与所做操作，不证明浏览器 quarantine、首次信任弹窗、全部 GUI 渲染/编辑、移动端或人类接受。缺 GUI 断言就明确写“启动 smoke”，不叫全功能验收。无需给简单文档更新反复启动 CI。

## 安装包图标单独验收

App 包内图标、磁盘镜像卷图标、外层 DMG 的 Finder 自定义图标和浏览器下载列表图标是不同层。分别检查实际资源及对应界面；本机外层文件的扩展属性不保证经 HTTP 下载后保留。若要求“下载包也有图标”，先确认所指层级，不能凭官网图标或挂载卷图标宣称所有浏览器/Finder 都通过。
